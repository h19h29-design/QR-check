# 기존소스 분석결과

기존 QR보안점검표는 `qr.zip`에서 추출했으며 분석본은 `legacy/original/`에 있다.

핵심 구조:

- Python Flask
- SQLite `inspections.db`
- 실별 제출 HTML 템플릿
- `static/uploads` 첨부 저장
- `static/qrcodes` QR 저장

핵심 개선 방향:

- 실별 DB 테이블을 단일 `submissions` 구조로 통합
- 실, 사람, 점검항목을 설정 데이터로 분리
- Google Apps Script, Sheet, Drive로 중간 서버를 대체
- Windows 관리자 프로그램은 로컬 SQLite 캐시와 출력/QR/설정 관리를 담당
