# HWP 출력 템플릿 안내

무료 배포 기본 출력은 XLSX와 HTML 인쇄입니다.

HWP 출력은 한글 프로그램이 설치된 Windows PC에서만 선택적으로 동작합니다.

권장 흐름:

1. 프로그램이 HTML 인쇄물을 먼저 생성한다.
2. 한글 COM(`HWPFrame.HwpObject`) 사용이 가능하면 HTML을 HWP로 열고 `.hwp`로 저장한다.
3. COM 사용이 실패하면 HTML 파일을 그대로 제공한다.

기존 결과보고서형 HWP는 출력 양식 참고용으로 분석했으며, 표/서명란 중심의 보안점검표 일일 출력에는 XLSX + HTML이 더 안정적이다.
