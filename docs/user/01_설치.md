# 01_설치 — 학교 담당자 설치 안내 (초안, live 화면 확인 후 확정)

> 이 문서는 구현 기준 안내다. Google 승인 화면의 실제 버튼명은
> Gmail 테스트 계정 검증 후 확정한다. 확인되지 않은 화면 설명은 적지 않는다.

## 준비물

1. 학교에서 승인한 Google 계정
2. 학교명, 관리자 표시 이름, 처음 점검할 장소
3. Windows 프로그램·개발 도구·API 키 불필요

## 순서 (설치센터 화면 기준)

1. **우리 학교용 만들기** — 데이터 저장 위치 설명 확인
2. **정보 입력** — 학교명·관리자 표시 이름·기본 장소 (브라우저에서만 처리)
3. **Google 연결** — 학교 계정 선택, 권한 내용 확인 후 승인
4. **Google 설정** — Apps Script API 접근 허용이 꺼져 있으면 안내 화면대로 설정 후 재검사
5. **생성 대기** — 폴더·시트·스크립트·배포 자동 생성 (중단되면 이어하기)
6. **학교 앱 승인** — 관리자 주소 첫 접속 시 Google 승인 1회
7. **시험** — 시험 QR 제출 → 관리자에서 확인될 때만 완료
8. **완료** — 관리자 주소 보관 (즐겨찾기 + 학교 Drive 설치안내문)

## 실패 시

- `다시 시도` → 같은 단계부터 이어진다. 처음부터 다시 만들지 않는다.
- `Google 계정 확인` → 설치를 시작한 계정과 같은 계정인지 확인한다.
- `관리자에게 문의` → 기관 정책 차단 시 학교 전산 담당자에게 외부앱 허용을 요청한다.
  개인 계정 우회는 하지 않는다.

## 설치 완료의 정의

시험 제출 1건이 관리자 화면에 보이고, 관리자 주소를 보관했을 때 완료다.
배포 URL 발급·화면 미리보기만으로는 완료가 아니다.
