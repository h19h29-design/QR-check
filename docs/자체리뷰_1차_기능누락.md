# 자체리뷰 1차: 기능 누락

## 확인

- QR 제출: 구현
- 담당자/당직자 선택: 구현
- 이상 무/이상 유: 구현
- 항목별 첨부파일: 구현
- 특이사항: 구현
- 제출 완료 화면: 구현
- 관리자 날짜별 조회: 구현
- 상세보기: 구현
- 관리자 확인: 구현
- 이상 없음 일괄확인: 구현
- 이상 있음 개별확인 정책: 구현
- CSV/XLSX: CSV는 Apps Script, XLSX는 관리자 프로그램에서 구현
- QR 생성: 관리자 프로그램 구현
- 출력 양식: XLSX/HTML/HWP fallback 구현

## 보완 필요

- 실제 Google 계정 배포 테스트는 사용자가 직접 수행해야 한다.
- 관리자 프로그램의 설정 관리 UI는 MVP 수준이며 향후 수정/삭제/순서 변경 UX 고도화가 필요하다.
