# ADR 20260426. Google Drive 중간서버형 구조 채택

## 상태

채택

## 배경

학교 PC는 09:00~16:00에만 켜질 수 있고, 점검자는 저녁에도 스마트폰으로 제출해야 한다. 무료 배포용이므로 개발자 서버, NAS, 유료 클라우드 서버를 사용할 수 없다.

## 결정

학교별 Google Sheet와 Google Drive를 원본 저장소로 사용하고, Google Apps Script를 서버리스 중간 계층으로 사용한다.

## 결과

- 점검자는 학교 PC가 꺼져도 제출 가능
- 관리자는 퇴근 후 관리자 웹앱으로 확인 가능
- 학교별 데이터가 각 학교 Google 계정에 분리 저장됨
- Google Apps Script 권한 승인과 무료 할당량이라는 운영 제약은 문서화 필요
