## 주요 결정

- 중앙 서버 없이 학교별 Google Drive/Sheet를 사용한다.
- 점검자는 Google 로그인 없이 QR token으로 제출한다.
- 관리자 이메일 확인은 목표로 두되 Apps Script 한계 때문에 token fallback을 병행한다.
- HWP는 기본 필수가 아니라 선택 변환이며 XLSX/HTML을 안정 fallback으로 제공한다.
