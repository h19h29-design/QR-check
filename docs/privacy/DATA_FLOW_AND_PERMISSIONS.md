# DATA_FLOW_AND_PERMISSIONS — 데이터 흐름과 권한 (학교·학부모 안내용)

## 저장 위치 (학교 소유)

| 자료 | 위치 | 제작자 접근 |
|---|---|---|
| 점검 기록·확정 이력 | 학교 Google Sheet | 없음 (설치 시 브라우저 일시 권한만, 영구 보관·서버 전송 없음) |
| 사진·첨부·출력·백업 | 학교 Google Drive 비공개 폴더 | 없음 |
| 점검 웹앱 코드 | 학교 Apps Script (소유자 열람 가능) | 소스 제공자이나 운영 접근 없음 |
| 관리자 목록 | 학교 Sheet (Google 이메일 기반) | 없음 |
| QR 토큰 원문 | 발급 시 1회 화면 표시, 이후 hash만 저장 | 없음 |
| 학교 비밀키(HMAC) | 학교 ScriptProperties | 없음 |

## 수집하지 않는 것

- 설치센터는 학교명 외 직원 명단·사진·비밀번호를 입력받지 않는다.
- Google 비밀번호, OAuth refresh token, 학교 비밀키를 서버에 보관하지 않는다.
- 분석·오류추적·광고 전송을 설치센터에 붙이지 않는다.

## 권한과 철회

- 설치센터 권한: Google 계정 → 보안 → 타사 액세스에서 해제 가능.
- 학교 앱 권한: 학교 Script 프로젝트 설정에서 직접 관리.
- 해제 후에도 학교 QR 제출·관리자 조회·출력은 정상 작동한다 (독립성 검증 항목).

## 한계 고지

- QR 이름 선택은 신원 인증·전자서명이 아니다.
- Sheet 편집 권한자는 원본을 직접 바꿀 수 있어 변조 불가능한 로그가 아니다.
- 같은 Drive 안 백업은 계정 분실 대비가 아니다. 외부 내려받기를 병행한다.
