# 자체리뷰 2차: 보안/배포/초보자 사용성

## 보안

- secret/token 하드코딩 없음
- submit token hash 저장
- sync key hash 저장
- 첨부 MIME/용량 제한 구현
- audit_log 구현
- 관리자 이메일 확인 한계 문서화

## 배포

- PowerShell 스크립트 제공
- Apps Script 수동 배포 가이드 제공
- PyInstaller 패키징 스크립트 제공

## 초보자 사용성

- README에 복사 가능한 명령 포함
- 학교별 초기 설정 가이드 작성
- QR 부착 가이드 작성
- FAQ 작성

## 남은 위험

- Apps Script 배포 권한을 잘못 설정하면 점검자 접속이 막히거나 관리자 화면이 과도하게 열릴 수 있다.
- Google 무료 할당량 초과 가능성이 있다.
- HWP 출력은 한글 설치 여부에 좌우된다.
