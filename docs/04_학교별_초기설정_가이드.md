# 04. 학교별 초기설정 가이드

이 문서는 Google Apps Script를 처음 배포하는 담당자가 순서대로 따라 할 수 있도록 정리한 체크리스트다. 중간에 관리자 토큰과 Desktop Sync Key가 화면에 한 번 표시되므로, 시작 전에 학교가 관리하는 비밀번호 보관 장소를 준비한다.

## 1. 관리자 Google 계정 준비

학교 공용 Google 계정 또는 업무용 Google 계정을 권장한다. 개인 Gmail을 사용할 수는 있지만 담당자 변경, 파일 소유권, 개인정보 관리에 주의해야 한다.

주의:

- 실제 Google 비밀번호, Google Client Secret, 관리자 토큰, Desktop Sync Key를 이 저장소나 공개 문서에 적지 않는다.
- Google Sheet와 Drive 폴더는 기본 비공개 상태로 둔다. 점검자 접속을 위해 공개하는 것은 Sheet/Drive가 아니라 Apps Script 웹앱이다.
- 학교 Workspace 정책상 `모든 사용자` 웹앱 배포가 막혀 있으면 점검자 무로그인 제출은 동작하지 않을 수 있다. 이 경우 관리자에게 Apps Script 웹앱 공개 정책을 먼저 확인한다.

## 2. Google Sheet 생성

Google Drive에서 새 Sheet를 만들고 이름을 `QR보안점검표_학교명`으로 바꾼다.

## 3. Apps Script 코드 넣기

Sheet에서 `확장 프로그램 > Apps Script`를 열고 `apps-script/` 폴더의 파일을 같은 이름으로 만든다.

확인할 파일:

- `.gs` 파일은 Apps Script의 스크립트 파일로 만든다.
- `.html` 파일은 HTML 파일로 만든다.
- `appsscript.json`은 Apps Script 편집기의 프로젝트 설정에서 매니페스트 표시를 켠 뒤 같은 내용으로 맞춘다.

코드를 붙여넣은 뒤 저장한다. 저장 전후로 실제 토큰이나 학교 비밀번호를 코드에 직접 넣지 않는다.

## 4. 웹앱 배포와 권한 승인

1. Apps Script 편집기에서 `배포 > 새 배포`를 누른다.
2. 유형은 `웹 앱`을 선택한다.
3. 실행 사용자는 `나`로 설정한다.
4. 액세스 권한은 점검자 무로그인 제출이 필요하면 `모든 사용자`로 설정한다.
5. 배포를 누른다.
6. Google 권한 승인 화면이 나오면 학교 관리자 계정으로 승인한다.
7. 승인 화면의 앱 이름과 계정이 방금 만든 학교용 프로젝트인지 확인한다. 모르는 프로젝트나 개인이 보낸 링크라면 승인하지 않는다.

이 권한은 Apps Script가 학교 관리자 계정 권한으로 Sheet에 기록하고 Drive에 첨부파일을 저장하기 위한 것이다. 점검자에게 Google Drive 편집 권한을 주는 절차가 아니다.

## 5. 초기 설정 실행

Apps Script 편집기 상단의 함수 선택 목록에서 `createInitialSetupKey`를 선택하고 실행한다. 실행 결과에 표시되는 초기 설정 키를 복사한다. 이 키는 최초 설정 선점을 막기 위한 일회성 값이며, 학교 담당자만 알고 있어야 한다.

배포 URL을 복사한 뒤 브라우저 주소창에 다음처럼 연다.

```text
https://script.google.com/macros/s/배포_ID/exec?page=setup
```

초기 설정 화면에서 초기 설정 키, 학교명, 관리자 Google 이메일을 입력하고 `Google 저장소 만들기`를 누른다. 성공하면 결과 영역에 다음 값이 표시된다.

- 관리자 토큰
- Desktop Sync Key
- Drive 폴더 ID

관리자 토큰과 Desktop Sync Key는 다시 보기 어렵다고 생각하고 즉시 안전한 곳에 보관한다. 공개 문서, 단체 메신저, 이메일 본문, QR 출력물에는 적지 않는다.

## 6. 관리자 프로그램 연결

1. Windows 관리자 프로그램 실행
2. `설정` 메뉴 열기
3. 학교명 입력
4. 관리자 Google 이메일 입력
5. Apps Script URL 입력
6. Desktop Sync Key 입력
7. QR 저장 폴더와 출력물 저장 폴더 선택
8. `연결 테스트`

연결 테스트가 실패하면 먼저 배포 URL이 `/exec`로 끝나는지, Desktop Sync Key 앞뒤에 공백이 없는지, Apps Script 배포 권한이 `모든 사용자`인지 확인한다.

## 7. 실/담당자 초기 등록

1. `실 관리`에서 행정실, 시설관리실, 인쇄실 등을 추가한다.
2. `담당자/당직자 관리`에서 이름을 추가한다.
3. `점검항목 관리`에서 필요한 항목을 확인한다.
4. `설정 > 로컬 설정을 Google로 업로드`를 눌러 Google Sheet에 반영한다.

## 8. QR 생성

`QR 생성` 메뉴에서 실별 QR을 만들고 A4 출력용 HTML을 인쇄한다.

QR에는 `room_id`와 `submit_token`이 포함된다. QR 사진이 외부로 유출되면 그 실의 제출 권한이 유출된 것으로 보고 토큰을 재발급한 뒤 QR을 다시 출력한다.

## 9. 배포 후 확인

1. 스마트폰에서 QR 1개를 스캔해 점검표가 열리는지 확인한다.
2. 테스트 제출을 1건 보낸다.
3. 관리자 웹 `?page=admin`에서 테스트 제출이 보이는지 확인한다.
4. Windows 관리자 프로그램에서 동기화 후 같은 기록이 보이는지 확인한다.
5. Google Sheet와 Drive 폴더가 `링크가 있는 모든 사용자 편집 가능`으로 열려 있지 않은지 확인한다.

## 실사용 가능 조건

Apps Script 배포만 끝났다고 바로 실사용 상태가 되는 것은 아니다. 반드시 `연결 테스트`, `로컬 설정을 Google로 업로드`, `QR 생성`까지 완료해야 한다.
