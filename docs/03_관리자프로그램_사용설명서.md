# 03. 관리자프로그램 사용설명서

## 첫 실행

1. `admin-desktop/scripts/run_dev.ps1`로 실행한다.
2. 왼쪽 메뉴에서 `설정`을 연다.
3. 학교명, 관리자 이메일, Apps Script URL, Desktop Sync Key를 입력한다.
4. QR 저장 폴더와 출력물 저장 폴더를 확인한다.
5. `설정 저장`을 누른다.
6. `연결 테스트`로 URL과 Desktop Sync Key를 함께 확인한다.

설치 EXE로 받은 경우에는 `QR_security_check_setup_v버전_yyyyMMdd-HHmmss.exe`를 실행하면 현재 사용자 폴더에 설치되고 바탕화면 바로가기가 만들어진다. 설치 후에는 프로그램 왼쪽 메뉴의 `도움말/매뉴얼`에서 초기 설정과 사용법을 바로 확인할 수 있다.

## 프로그램 안 매뉴얼

왼쪽 메뉴의 `도움말/매뉴얼`에는 다음 내용이 들어 있다.

- 처음 설치한 뒤 할 일
- Google Sheet / Apps Script 최초 설정 순서
- 실/담당자/당직자/점검항목 등록
- 로컬 설정 Google 업로드
- QR 생성과 부착
- 점검자 모바일 제출 방법
- 점검기록 조회와 관리자 확인
- 출력/보관 방법
- 자주 생기는 문제와 보안 주의사항

## 실 관리

`실 관리 > 실 추가`를 누르고 실명을 입력한다. 실 추가 시 `room_id`와 `submit_token`이 생성되며, token 원문은 로컬 PC의 별도 테이블에 보관된다.

실/담당자/점검항목을 바꾼 뒤에는 `설정 > 로컬 설정을 Google로 업로드`를 눌러야 QR 제출 서버가 새 설정을 알 수 있다.

## 담당자/당직자 관리

`담당자/당직자 관리`에서 담당자 또는 당직자를 추가한다.

## 점검항목 관리

기본 항목은 다음 5개다.

- 서류보관상태
- 청소상태
- 소등상태
- 화기단속상태
- 문단속상태

추가 항목은 `점검항목 추가`로 만든다.

## QR 생성

1. `설정 > 로컬 설정을 Google로 업로드`를 먼저 실행한다.
2. `QR 생성` 메뉴를 연다.
3. `등록된 실 QR PNG와 A4 부착용 HTML 생성`을 누른다.
4. 생성된 PNG와 HTML을 출력하여 실 출입문에 부착한다.

QR 저장 폴더와 A4 출력물 저장 폴더는 `설정` 메뉴에서 바꿀 수 있다.

## 점검기록 조회

- 시작일/종료일로 기간을 선택한다.
- 실을 선택하거나 `전체`로 둔다.
- 상태를 `전체`, `이상 있음`, `이상 없음`, `미확인`, `확인 완료` 중 선택한다.
- `조회`를 누른다.
- 행을 더블클릭하면 상세보기 창이 열린다.
- 이상 있음 기록은 상세보기에서 개별확인한다.
- 이상 없음 기록은 `조회 범위 이상 없음 일괄확인`으로 한 번에 확인할 수 있다.
- Apps Script URL과 Desktop Sync Key가 설정되어 있으면 개별확인/일괄확인이 Google Sheet 원본에도 함께 반영된다.
- Google 반영에 실패하면 경고창이 뜬다. 이 경우 로컬 확인 처리는 남아 있으므로 네트워크와 Sync Key를 확인한 뒤 다시 동기화한다.

## 출력/보관

- 시작일/종료일과 실을 선택한다.
- `엑셀 출력`: 조회 범위 보관용 XLSX 생성
- `HTML 인쇄 출력`: 조회 범위 브라우저 인쇄용 HTML 생성
- `HWP 출력 또는 fallback`: 한글 COM 사용 가능 시 HWP, 실패 시 HTML 생성
- 저장 위치는 `설정` 메뉴의 출력물 저장 폴더에서 바꾼다.

## Google 관리자 웹

퇴근 후에는 Apps Script 배포 URL 뒤에 `?page=admin`을 붙여 브라우저 관리자 화면을 사용할 수 있다.

- 시작일/종료일 기간 조회
- 실별 조회
- 이상 있음/이상 없음/미확인/확인 완료 필터
- 현재 조회 조건 CSV 다운로드
- 이상 없음 일괄확인
- 이상 있음 상세보기 후 개별확인
