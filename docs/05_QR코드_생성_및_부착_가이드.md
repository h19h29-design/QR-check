# 05. QR코드 생성 및 부착 가이드

## QR URL 형식

```text
https://script.google.com/macros/s/{DEPLOYMENT_ID}/exec?page=submit&roomId={room_id}&submitToken={submit_token}
```

## 생성 방법

1. 관리자 프로그램에서 실을 추가한다.
2. 실마다 `room_id`와 `submit_token`이 생성된다.
3. `QR 생성` 메뉴에서 PNG를 만든다.
4. A4 부착용 HTML을 출력한다.

## 부착 문구 예시

```text
퇴실 전 QR을 스캔하고 보안점검표를 제출해 주세요.
이상 없으면 이름 선택 후 바로 제출하면 됩니다.
```

## QR 유출 시

QR URL에는 제출 권한이 포함된다. 외부 유출이 의심되면 해당 실의 submit token을 재발급하고 QR을 다시 출력한다.
