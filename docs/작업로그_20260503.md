# 작업로그 2026-05-03

## 실배포 안정화

- 실제 학교 배포 전 운영 리스크를 기준으로 추가 점검했다.
- Windows 관리자 프로그램의 Desktop Sync Key 로컬 저장 방식을 개선했다.
  - 저장 시 Windows DPAPI 보호값으로 저장한다.
  - 앱 실행 시 현재 Windows 사용자 계정으로 복호화해 사용한다.
  - 다른 PC/다른 Windows 계정에서는 다시 입력해야 할 수 있다.
- Google 동기화 기준 시각을 Apps Script 서버가 내려주는 `next_since`로 저장하도록 변경했다.
- Apps Script 제출 검증을 강화했다.
  - 담당자/당직자 ID가 실제 설정에 존재하고 활성 상태인지 확인
  - 실 전용 담당자/당직자 여부 확인
  - 점검항목 상태값 정규화
  - 특이사항과 client_info 길이 제한
  - 첨부파일 수 제한
  - 이미지/PDF MIME과 파일 signature 검증
- 첨부파일 업로드 실패 시 제출 레코드가 먼저 저장되어 재전송이 꼬일 수 있는 흐름을 보완했다.
- 관리자 웹 CSV 다운로드는 URL token 노출 없이 Blob 다운로드 구조를 유지한다.
