# 작업로그 2026-05-16

## 설치파일/내장 매뉴얼 보강

- Windows 관리자 프로그램 왼쪽 메뉴에 `도움말/매뉴얼` 페이지를 추가했다.
- 내장 매뉴얼에는 설치 후 첫 설정, Google Sheet/Apps Script 설정, 실/담당자/점검항목 등록, QR 생성, 점검자 제출, 관리자 조회/확인, 출력/보관, 문제 해결, 보안 주의사항을 넣었다.
- 첫 실행 시 Google 연결 정보가 없으면 기존처럼 `설정` 화면이 먼저 열리도록 유지했다.
- `admin-desktop/scripts/package_installer.ps1`을 추가했다.
  - `package.ps1`로 배포 ZIP을 만든 뒤 버전명이 들어간 배포 ZIP을 다시 만든다.
  - 배포 ZIP을 내부 payload로 포함하는 단일 설치 EXE를 생성한다.
  - 설치 EXE는 관리자 권한 없이 `%LOCALAPPDATA%\QR보안점검표\배포패키지`에 설치한다.
  - 바탕화면과 시작 메뉴에 `QR보안점검표 관리자` 바로가기를 만든다.
  - 설치 EXE 내부 payload에 관리자 EXE, Apps Script 코드, README가 포함되어 있는지 검증한다.
- README와 실배포 `README_먼저읽기.md`에 설치 EXE 생성/사용 방법을 추가했다.
