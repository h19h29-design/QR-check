## 기존 동작

기존 시스템은 Flask 서버를 학교 PC에서 `0.0.0.0:8080`으로 실행하고, 실별 QR이 `/submit/<room>`으로 연결되는 구조다. SQLite `inspections.db`에 실별 테이블을 만들고, 항목별 상태와 첨부파일명을 저장한다.

주요 라우트:

- `/admin`: 관리자 PIN 로그인
- `/`: 관리자 점검 기록 홈
- `/submit/<room>`: 실별 모바일 점검 제출
- `/detail/<room>/<record_id>`: 제출 상세보기
- `/verify_record/<room>/<record_id>`: 관리자 확인
- `/admin/records`: 전체 기록 날짜별 조회
- `/admin/export_excel`: 엑셀 다운로드
- `/generate_qr`: 실별 QR PNG 생성
- `/uploads/<filename>`: 첨부파일 조회
