# 작업로그 2026-04-27

## UI 가독성 조정

- 전역 폰트 확대 배율을 낮춰 화면 전체가 과하게 커 보이지 않도록 조정했다.
- 좌측 메뉴, 상단 제목, Google 상태 배지, 대시보드 제목/타일/카드 글자 크기를 줄였다.
- 최종 조합형 GUI 미리보기 HTML도 축소된 글자 크기 기준으로 갱신했다.

## 표시순서 안내

- 실 관리, 담당자/당직자 관리, 점검항목 관리의 `순서` 라벨을 `표시순서`로 변경했다.
- 낮은 숫자일수록 먼저 보인다는 안내문과 툴팁을 추가했다.
- 삭제/복구 방식은 기존처럼 실제 삭제가 아닌 미사용 처리로 유지했다.

## Google 설정 안내 내장

- 관리자 프로그램 `설정` 화면에 Google Sheet/Apps Script 최초 설정 방법 10단계 안내를 추가했다.
- Apps Script Web App URL과 Desktop Sync Key 입력칸에 초보자용 힌트를 추가했다.

## 패키징 보강

- Windows PowerShell에서 UTF-8 BOM 없는 스크립트의 한글 실행파일 이름이 깨질 수 있어 `package.ps1`에서 앱 이름을 유니코드 코드포인트로 조립하도록 수정했다.

## 추가 UI 수정

- 점검기록과 출력/보관 화면의 날짜/실/상태 필터 폭을 고정해 한 줄이 자연스럽게 보이도록 조정했다.
- 날짜 선택 달력 버튼과 선택상자 드롭다운 버튼을 같은 분위기의 작은 버튼 스타일로 맞췄다.
- 출력/보관 화면의 출력물 미리보기를 오른쪽 좁은 영역에서 하단 큰 영역으로 이동했다.
- 표시순서 안내에 `10번은 100번보다 먼저 표시`된다는 예시를 추가했다.
