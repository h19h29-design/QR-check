# 작업로그 2026-04-28

## 배포 전 검토

- QA/Release 서브에이전트와 Security/Beginner UX 서브에이전트 2명으로 배포 전 검토를 수행했다.
- `admin-desktop/scripts/build.ps1`로 pytest 10개 통과를 확인했다.
- `admin-desktop/scripts/package.ps1 -SkipInstall`로 pytest, PyInstaller 빌드, 다운로드 폴더 배포 ZIP 생성을 확인했다.
- 최종 ZIP 내부 필수 파일을 확인했다.
  - Windows 관리자 프로그램 exe
  - Apps Script 코드
  - 관리자/설치 문서
  - UI 미리보기
  - 샘플 데이터
- 다운로드 폴더 배포본의 exe가 시작되고 5초 이상 유지되는 smoke 테스트를 수행했다.

## 수정 사항

- `package.ps1`가 테스트, 빌드, 실배포 폴더/ZIP 생성을 한 번에 처리하도록 보강했다.
- 실배포 README의 폴더명과 실제 배포 구조를 맞췄다.
- Google 배포 권한, 점검자 무로그인 리스크, Desktop Sync Key 보관/재발급 안내를 문서에 보강했다.
- 관리자 웹 CSV 다운로드에서 관리자 토큰 fallback이 URL query string에 남지 않도록 `google.script.run`과 Blob 다운로드 방식으로 변경했다.

## 남은 실제 운영 검증

- 실제 학교 Google 계정으로 Apps Script 배포와 권한 승인 테스트가 필요하다.
- 실제 한글 설치 PC에서 HWP 변환 테스트가 필요하다.
- 다른 Windows PC에서 ZIP 압축 해제 후 실행 확인이 필요하다.
