## 목표

기존 수기 보안점검표철을 대체할 수 있도록 날짜별/실별 보안점검표 출력물을 만든다.

필수 요소:

- 점검일
- 실명
- 담당자/당직자
- 5개 기본 점검항목
- 이상 있음 표시
- 특이사항
- 관리자 확인일시
- 담당자 서명란
- 관리자 서명란

판단:

- HWPX 직접 생성은 가능하지만 문서 구조 검증과 양식 재현 난도가 있다.

## 구현

- `export_excel.py`: 보관용 XLSX
- `export_pdf_or_html.py`: 브라우저 인쇄용 HTML
- `export_hwp.py`: 한글 COM 사용 가능 시 HWP 저장, 실패 시 HTML fallback

## fallback 정책

1. XLSX: 가장 안정적인 기본 보관 출력
2. HTML 인쇄: 수기철 대체 양식 미리보기/인쇄
3. HWP: 한글 설치 PC에서만 선택 실행
4. PDF: 브라우저 인쇄의 PDF 저장 기능 사용
