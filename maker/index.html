초기 설정과 연결을 확인합니다.

초기 설정 확인 완료는 초기 설정 입력 확인이며, 실제 QR 제출·시트 기록·첨부 동작 확인은 별도로 필요합니다. 관리자 화면에서 초기 설정을 한 뒤 연결 검사를 진행하세요.

  1. 초기 설정 키 만들기학교 계정의 Apps Script 편집기에서 아래 함수를 1회 실행합니다.
    showSetupKeyForOwner
  2. 학교 정보와 관리자 설정실제로 생성된 주소의 ?page=setup 화면에서 학교명, 관리자와 설정 키를 입력합니다.
    관리자 주소는 실제 리소스 생성 후 표시됩니다.
    관리자 주소
  3. 연결 검사 및 주소 보관테스트 제출이 학교 저장소에 남는지 확인하고 관리자 주소를 보관합니다. 연결 검사가 끝나면 관리자 주소를 별도로 보관한 뒤 초기 설정 확인 완료 버튼을 누르세요. 이 버튼은 초기 설정 확인이며 QR 제출·첨부 동작 성공을 증명하지 않습니다.
