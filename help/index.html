전체 13개 질문

Google 연결 정보가 준비되지 않았다는 안내가 나와요.
설치센터의 Google OAuth 클라이언트 값이 비어 있어 연결이 차단된 상태입니다. 만들기 화면의 연결 버튼도 비활성화되어 있습니다. 설치센터 운영자가 연결 설정을 준비하고 학교 계정에서 권한이 허용되는지 확인해야 합니다. 오류를 무시하고 강제로 완료 처리해서는 안 됩니다.
학교용으로 만들 때 무엇이 필요한가요?
학교에서 승인한 Google 계정, 학교명, 관리자 이메일과 설치 계정 이메일이 필요합니다. 초기 점검 장소 목록도 준비해 주세요. 이후 실제 관리자 초기 설정과 테스트 제출을 진행합니다.
아직 관리자 주소가 보이지 않아요.
학교용 리소스와 웹앱의 실제 생성·배포가 끝나야 주소가 표시됩니다. 생성 전에는 임의의 주소를 만들어 사용하지 않습니다. 릴리스 정보가 미게시 상태이므로 실제 배포 준비가 먼저 필요합니다.
설치 도중 오류가 나면 처음부터 해야 하나요?
원본 소스는 설치 상태에 맞는 다시 시도 흐름을 갖고 있습니다. 먼저 오류와 현재 상태를 확인하고 담당자 안내에 따라 재시도하세요. 연결·생성이 끝났다는 근거 없이 다음 상태로 넘기지 않습니다. 이어하기 정보는 자동 저장되지 않으므로 필요한 정보는 안전하게 보관해야 합니다.
권한 요청이 거부되거나 계정이 다르다고 나와요.
학교에서 승인한 계정으로 연결했는지, 입력한 이메일과 실제 연결 이메일이 같은지 확인하세요. 기관 계정의 사용 제한으로 승인이 되지 않으면 학교 관리자에게 허용 범위를 확인합니다. 정책을 우회하거나 보안 경고를 무조건 무시하지 마세요.
401, 429 또는 5xx 오류가 표시돼요.
첨부 도움말은 401에서 연결 만료 여부와 재로그인을, 429·5xx에서 일시적 제한이나 서버 오류 가능성을 확인하도록 안내합니다. 과도한 반복 클릭을 피하고 오류 내용과 발생 단계를 학교 관리자에게 전달하세요.
Apps Script API 사용 중지 안내가 나와요.
학교 계정에서 Apps Script API 사용이 허용되어 있는지 확인해야 합니다. 학교의 계정 관리 절차에 따라 담당자가 사용 가능 여부를 검토한 뒤 다시 시도합니다.
점검 기록과 사진은 어디에 보관되나요?
점검 기록은 학교 소유 Google Sheets에, 첨부 자료는 학교 소유 Google Drive 폴더에 보관하는 구조입니다. 학교 계정의 Apps Script 웹앱이 저장을 연결합니다. 설치 안내 사이트는 학교별 기록을 수집하는 중앙 관리 화면이 아닙니다.
누가 기록을 수정할 수 있나요?
Google Sheets 편집 권한을 가진 사람은 기록을 변경할 수 있습니다. 편집 권한을 필요한 관리자에게만 부여하고 공유 범위를 정기적으로 확인하세요. 이름 선택만으로 기록의 작성자 신원을 강하게 증명할 수는 없습니다.
학교 계정을 잃어버리거나 사용을 중단하면요?
중요 기록을 정기적으로 내보내어 별도 보관하고 소유 계정·공유 범위를 점검하세요. 사용을 중단할 때는 계정의 타사 접근 권한, Apps Script 배포·권한, 문서·폴더 공유를 정리합니다. 기록 삭제는 학교의 보관 기준을 먼저 확인한 뒤 진행합니다.
별도 앱 설치나 점검자 로그인이 필요한가요?
웹브라우저를 사용하는 방식이므로 별도 앱 설치는 필요하지 않습니다. 공용 점검 제출 흐름은 Google 로그인 없이 이름을 선택해 제출합니다. 설치·관리 담당자는 학교에서 승인한 Google 계정을 사용합니다.
체험 페이지에서 등록한 내용이 사라졌어요.
정상적인 동작입니다. 체험 페이지는 가상 데이터만 현재 페이지의 메모리에서 처리하며 영구 저장을 하지 않습니다. 새로고침하거나 페이지를 이동하면 입력한 체험 기록과 확인 상태가 초기화됩니다.
체험이 되면 실제 학교에서도 바로 쓸 수 있나요?
체험은 입력 방식과 화면 구성을 보여줄 뿐 실제 Google 연결, QR 인식, 휴대전화 제출과 저장의 성공을 증명하지 않습니다. 실제 운영 전에는 학교 계정과 사용 기기에서 생성·설정·테스트 제출을 따로 확인해야 합니다.
