초기 설정 키 만들기

아래 버튼으로 학교 계정의 Apps Script 편집기를 엽니다.

1. Apps Script 편집기 열기
  1. 왼쪽 파일 목록에서 Auth.gs를 누릅니다. 다른 파일에서는 필요한 함수가 목록에 보이지 않을 수 있습니다.
  2. 위쪽의 현재 함수 이름과 ▼가 표시된 곳을 누르고 showSetupKeyForOwner를 선택합니다.
  3. 왼쪽의 삼각형 아이콘이 있는 실행을 누릅니다. Google 권한 화면이 나오면 설치한 학교 계정으로 승인합니다.
  4. 실행이 끝나면 위쪽의 실행 로그를 누릅니다.
  5. 로그에서 SETUP_KEY: 뒤의 긴 값만 복사합니다. SETUP_KEY: 글자는 복사하지 않습니다.
